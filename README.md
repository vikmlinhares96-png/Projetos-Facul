# 🚀 Dan Labs 3D — Landing Page

> Projeto desenvolvido durante o **1º Semestre do curso de Ciência da Computação** para praticar conceitos fundamentais de desenvolvimento Web Front-End (HTML5 e CSS3).

---

## 📌 Sobre o Projeto

O **Dan Labs 3D** é uma landing page conceitual para uma plataforma dedicada à apresentação e comercialização de peças e esculturas impressas em 3D[cite: 1]. 

O objetivo principal deste projeto foi construir uma interface moderna e responsiva aplicando regras estritas de otimização de código, estrutura semântica limpa e estilização sem o uso de frameworks externos.

---

## 🎯 Desafios e Aprendizados

Durante a construção desta página, foram trabalhados os seguintes conceitos:

* **HTML5 Semântico:** Estruturação da página utilizando boas práticas e tags específicas (`<header>`, `<main>`, `<nav>`, `<footer>`).
* **CSS3 Incorporado:** Estilização aplicada diretamente no arquivo HTML com foco em organização e reuso de regras[cite: 2].
* **Otimização de Código:** Restrição no número de elementos `<div>` e limite de linhas para manter o código enxuto e de fácil manutenção[cite: 2].
* **Design & UI:** Construção de um visual imersivo (efeito *glassmorphism* / fundo escuro) combinando tipografia e hierarquia visual[cite: 1].

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estrutura do site)
* **CSS3** (Estilização e layout)
